# Проверка игрового цикла — 21 сентября 2026

Godot 4.6.2, headless. Проверка настоящих сцен и контроллеров, без визуального прохождения экспортированной сборки.

## Исправлено и проверено

- Начальный OfflineMultiplayerPeer ошибочно считался сетевой сессией: save_game возвращал ERR_UNCONFIGURED. NetworkManager теперь очищает стандартный офлайн-peer при старте, сохраняя существующее соглашение проекта: null означает одиночную игру.
- Стрельба могла расходовать патроны во время использования аптечки. Добавлена блокировка в обработчик ввода и метод выстрела; также заблокирован запуск ближней атаки во время действия.
- Диагностический вывод персонажа больше не запрашивает multiplayer authority при отсутствии peer.

## Результаты

Новый alpha_gameplay_flow_test: PASS. Проверены настоящий старт/отмена/завершение перезарядки, сохранение количества патронов, скорость x0.5, невозможность запуска перезарядки и выстрела при лечении, возврат аптечки при сохранении, загрузка здоровья/инвентаря/боезапаса, обычный выстрел после действия с расходом одного патрона. В некоторых существующих тестах при выходе остаются предупреждения ObjectDB/resources still in use. Это не чистый общий прогон без ошибок и не доказательство утечки в длительной игре. Новый сценарий после завершения кратких эффектов выходит без этих предупреждений.

## Открытый блокер LAN

Запущены два отдельных процесса на localhost:2467 через tools/lan_smoke.ps1, повторный прогон 50 секунд. Подключение и подтверждение готовности клиента есть, но тест не пройден: клиент получает Node not found / Failed to get path from RPC / Invalid packet received для Level/Y-Sort_Objects/Player2 и нескольких BanditBase/генерируемых врагов. Нужна отдельная коррекция идентичности и порядка появления сетевых узлов. Причина на уровне конкретного механизма пока не установлена.

Логи: alpha_lan_host.log, alpha_lan_client.log, alpha_gameplay_flow_test.log, alpha_*_test.log в этой папке.

## Границы проверки

Не проверены: полный бой с противниками, смерть/повторный старт, баланс, 30-минутная сессия, визуальное качество, экспорт и другое устройство. LAN-прогон на одном компьютере не заменяет проверку двух физических устройств. Готовность альфы этим прогоном не подтверждена.
